# The shell version
This version of the hamule is an interactive shell command line.

With all the calculators together in one place he can save a little
space on your drive. If you wonder why it's because they all share one
header/library/startup code.

It is almost the same as running them from the prompt one at a time.

It should work when compile under the gcc. We tested it in Linux and all
the calculators should work.

Just issue: `$ make shell`
It will build a binary called `hamule` for you to run.
